# Aliwkukh Bio

Минималистичный сайт-визитка в темной стилистике

## Локальный запуск

Откройте `index.html` в браузере.

## Деплой на Vercel

1. Импортируйте репозиторий в [Vercel](https://vercel.com/).
2. Framework Preset: `Other`.
3. Build Command: оставить пустым.
4. Output Directory: оставить пустым.

Vercel автоматически задеплоит статический сайт.
